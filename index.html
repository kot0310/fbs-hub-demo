    Что делает бот

    работает с сервера, без ручных запусков

    • Заказы, отмены и невыкупы — сразу в Telegram, вместе с остатком после списания.
    • Сбои передачи остатков: сообщение один раз. Если позже была успешная передача или ошибке больше 6 часов — не повторяется.
    • Сводки по расписанию: заказы, передачи, сбои, расхождения — без ручных отчётов.
    • Ответы на команды: «сводка», «остатки», «сбои» — частью команд можно управлять хабом прямо из чата.

    Бот на Bot API Telegram. Правило затухания сбоев — из рабочей системы: так повторно не рассылаются старые ошибки.

    Что умеет

    ходит в API хаба, а не в общий чат

    • Отвечает по данным хаба: заказы, остатки, передачи, реклама, приёмка — цифры из базы, не из головы.
    • Находит проблемные места: расхождения остатков, убыточные SKU, поставки без решения, кампании выше цели CPO.
    • По подтверждению выполняет действие в рабочей системе: передать остаток, собрать лист, включить автопилот.

    Демо отвечает на три вопроса; ответы построены на тех же данных, что и вкладки.
